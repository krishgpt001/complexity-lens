# Complexity Lens

A deployable Next.js 14 + TypeScript + Tailwind developer tool that provides a fast, local heuristic read on algorithmic complexity.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Production builds use `npm run build` and `npm start`.

The analyzer runs entirely in the browser and uses no environment variables, API keys, or server-side code upload. It can be deployed to Vercel as-is.
